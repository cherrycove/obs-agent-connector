# Quick Reference

This document is a compact reference for:

- supported Agents
- the most commonly used command-line parameters

## Supported Agents

| Agent | Integration | macOS | Linux | Windows | Notes |
| --- | --- | --- | --- | --- | --- |
| `claude` | Built into `obs-agent-connector` | `✅` | `✅` | `✅` | Stop / SessionEnd Hook adapter |
| `codebuddy` | Built into `obs-agent-connector` | `✅` | `✅` | `✅` | Stop / SessionEnd Hook plus native `index.json` replay; Linux x64 is product-validated |
| `codex` | Built into `obs-agent-connector` | `✅` | `✅` | `✅` | Stop Hook adapter plus built-in Codex trust/config handling |
| `cursor` | Built into `obs-agent-connector` | `✅` | `✅` | `✅` | Detects `~/.cursor`, prefers `cursor-agent`, and manages user-level Cursor Hooks |
| `dcode` | Built into `obs-agent-connector` | `✅` | `✅` | `✅` | Hooks v2 plus transcript replay; normal `Stop` plus failed `SessionEnd` fallback |
| `grok` | Built into `obs-agent-connector` | `✅` | `✅` | `✅` | Grok Build CLI 1.0.10+ TUI/headless; Hook journal plus terminal `updates.jsonl` replay |

| `openclaw` | `openclaw-otel-plugin` | `✅` | `✅` | `✅` | OpenClaw plugin |
| `qoder` | `qoder-otel-plugin` | `✅` | `✅` | `✅` | Auto-detects CN vs global layout and passes the matching `--variant` value |
| `workbuddy` | `workbuddy-otel-plugin` | `✅` | `❌` | `✅` | Uses the detected WorkBuddy profile directory and writes `gtrace.json` there |

## Agent Notes

| Agent | Notes |
| --- | --- |
| `claude` | Uses the built-in adapter and writes managed runtime config under `~/.obs-agent-connector/claude/`. |
| `codebuddy` | Uses the built-in adapter. The connector manages Hook entries in `~/.codebuddy/settings.json`. |
| `cursor` | Uses the built-in adapter, detects the local Cursor CLI family, and prefers `cursor-agent` when available. |
| `dcode` | Uses Hooks v2 in `~/.deepagents/hooks.json` and transcript JSONL under `~/.deepagents/transcripts/`. Start a new session or run `/reload` after installation. A failed `SessionEnd(reason=other)` produces an error root Trace without fabricated LLM or usage data. |
| `grok` | Uses `~/.grok/hooks/obs-agent-connector.json` and exact-session `updates.jsonl` replay. Restart Grok or run `/hooks`, select the Hooks tab, and press `l` to reload. Runtime files live under `~/.obs-agent-connector/grok/`. |
| `kiro` | Uses the built-in adapter with global Hooks in `~/.kiro/hooks/`, modern workspace-bucketed sessions under `~/.kiro/sessions/`, and legacy V3 sessions under `~/.kiro/sessions/cli/`. Telemetry requires `kiro-cli chat --v3` in an interactive TTY. |
| `dsh` | Discovery accepts either a `dsh` executable in `PATH` or an existing `~/.dsh` directory. The default profile is `web`, and runtime config is generated by `dsh-otel-plugin`. |
| `qoder` | Detects the local global vs CN layout and uses the matching variant automatically. |
| `qoder-cn` | Legacy compatibility target that always forces the CN layout. |
| `hermes` | Runtime enable/disable is not managed by this CLI because Hermes uses YAML config instead of the supported JSON structure. |
| `openclaw` | Runtime enable/disable is supported through `~/.openclaw/openclaw.json`, but `config <agent>` is still not supported because the plugin owns its private config shape. |
| `workbuddy` | Supported on macOS and Windows, but not on Linux. |

## Most Common Commands

```bash
obs-agent-connector list
obs-agent-connector status <agent>
obs-agent-connector discover
obs-agent-connector discover -u
obs-agent-connector install <agent>
obs-agent-connector config <agent> list

obs-agent-connector update <agent>
obs-agent-connector enable <agent>
obs-agent-connector disable <agent>
obs-agent-connector remove <agent>
obs-agent-connector uninstall
obs-agent-connector version
obs-agent-connector version -u
```

## Common Parameters

### Shared install parameters

These are the parameters most users need when running `install <agent>`:

| Parameter | Meaning |
| --- | --- |
| `--endpoint` | OBS / GTrace ingest endpoint. Example: `https://llm-openway.guance.com` |
| `--x-token` | Authentication token used for upload |
| `--agent-id` | Override the generated `agent_id` |
| `--agent-name` | Override the generated `agent_name` |
| `--static-base` | Override the installer base for this run. External OSS plugins are resolved from `<static-base>/agent_plugins` |
| `--yes` | Skip confirmation |
| `--dry-run` | Print the plan and command preview without changing anything |

Default identity behavior:

- if `--agent-id` is omitted, the CLI generates `agid_<uuidv4-without-dashes>`
- if `--agent-name` is omitted, the CLI generates `<hostname>_<agent>_<YYYYMMDD>`

External plugin contract:

- the connector passes only the common version, `--type gtrace`, endpoint, token, tags, and profile/variant arguments
- the plugin installer owns archive download, checksum verification, plugin registration, and its private runtime config
- the connector does not pass `--source` and does not read or write an external plugin's private `gtrace.json`

### Built-in adapter install parameters

These parameters apply to the built-in `claude`, `codebuddy`, `codex`, `cursor`, `dcode`, `grok`, and `kiro` adapters:

| Parameter | Meaning |
| --- | --- |
| `--trace-path` | Override the Trace upload path |
| `--metrics-path` | Override the Metrics upload path |
| `--header` | Add an HTTP header. May be repeated |
| `--tag` | Add a resource attribute. May be repeated |
| `--capture-content` | Content capture mode: `none`, `preview`, or `full` |
| `--max-chars` | Maximum captured content length |
| `--enable` | Set runtime `enabled=true` |
| `--disable` | Set runtime `enabled=false` |

CodeBuddy values are merged into the existing `~/.codebuddy/gtrace.json`, and unknown fields are preserved.

### `discover` parameters

| Parameter | Meaning |
| --- | --- |
| `-u` | Update installed plugins and install missing ones in one run |
| `--endpoint` | Override the stored endpoint for this run |
| `--x-token` | Override the stored token for this run |
| `--yes` | Skip confirmation |
| `--dry-run` | Print the discovery and install/update plan only |

### `update` parameters

| Parameter | Meaning |
| --- | --- |
| `--static-base` | Override the plugin download base URL for this run |
| `--yes` | Skip confirmation |
| `--dry-run` | Print the update plan only |

Notes:

- `update` accepts one Agent at a time
- `update claude`, `update codebuddy`, `update codex`, `update cursor`, `update dcode`, `update grok`, and `update kiro` reconcile the built-in Hook
- external plugin updates preserve the current runtime config

### `enable` / `disable` parameters

| Parameter | Meaning |
| --- | --- |
| `--dry-run` | Print the config change without writing it |

Current JSON runtime toggle support:

- `claude`
- `codebuddy`
- `codex`
- `cursor`
- `dcode`
- `grok`
- `kiro`
- `dsh`
- `opencode`
- `openclaw`
- `qoder`
- `workbuddy`

### `remove` parameters

| Parameter | Meaning |
| --- | --- |
| `--yes` | Skip confirmation |
| `--dry-run` | Print the removal plan only |
| `--purge-config` | Also remove runtime config. For CodeBuddy this also removes upload state |

### `version` parameters

| Parameter | Meaning |
| --- | --- |
| `-u` | Update the connector itself to the latest release |
| `--offline` | Show local version only and skip remote checks |

## Installer Script Parameters

### `install.sh`

| Parameter | Meaning |
| --- | --- |
| `--version` | Install a specific connector version. Default: `latest` |
| `--install-dir` | Target directory for the connector binary |
| `--config-dir` | Target connector config directory |
| `--download-base-url` | Connector package and metadata download base |
| `--endpoint` | OBS / GTrace ingest endpoint |
| `--x-token` | Authentication token |
| `--plugin-source` | Plugin source, currently `oss` or `github` |
| `--plugin-base-url` | Base URL for external plugin downloads |
| `--binary-only` | Update only the connector binary and do not write `config.json` |

### `install.ps1`

| Parameter | Meaning |
| --- | --- |
| `-Version` | Install a specific connector version. Default: `latest` |
| `-InstallDir` | Target directory for the connector binary |
| `-ConfigDir` | Target connector config directory |
| `-DownloadBaseUrl` | Connector package and metadata download base |
| `-Endpoint` | OBS / GTrace ingest endpoint |
| `-XToken` | Authentication token |
| `-PluginSource` | Plugin source, currently `oss` or `github` |
| `-PluginBaseUrl` | Base URL for external plugin downloads |
| `-BinaryOnly` | Update only the connector binary and do not write `config.json` |
| `-NoPathUpdate` | Skip updating the user PATH |

## Typical Examples

Install the built-in CodeBuddy adapter:

```bash
obs-agent-connector install codebuddy --yes
```

Install the built-in Grok Build adapter:

```bash
obs-agent-connector install grok --yes
```

Install one external plugin with explicit endpoint and token:

```bash
obs-agent-connector install dsh \
  --endpoint https://llm-openway.guance.com \
  --x-token agent_xxx \
  --yes
```

Discover everything and sync installed plugins:

```bash
obs-agent-connector discover -u --yes
```

Remove one plugin but keep its config:

```bash
obs-agent-connector remove codex --yes
```

Update the connector itself:

```bash
obs-agent-connector version -u
```
